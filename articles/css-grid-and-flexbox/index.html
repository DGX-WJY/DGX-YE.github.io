CSS Grid 与 Flexbox 的取舍

布局不是语法考试，理解空间关系之后，选择会变得很自然。

2026年7月22日1 分钟阅读#CSS#布局#前端

选择布局模型时，先问内容主要沿一个方向排列，还是需要同时控制行与列。这个问题往往比记住属性列表更有用。

Flexbox 适合一维排列：导航栏、按钮组、工具栏以及需要根据内容伸缩的行列。它擅长分配剩余空间，也能自然处理元素顺序和对齐。

Grid 更适合二维结构：页面分区、卡片矩阵和需要对齐行列轨道的布局。先定义轨道，再让内容进入网格，能让整体关系更明确。

两者并不互斥。常见做法是外层用 Grid 管理页面区域，组件内部用 Flexbox 对齐按钮和文字。让布局跟随内容结构，而不是让内容迁就某个属性。
